# El Kiosko · Web

Landing page de la agencia El Kiosko.

## Empezar
1. En Visual Studio Code, abre la paleta de comandos (Cmd+Mayús+P en Mac o Ctrl+Mayús+P en Windows), escribe **Git: Clone** y pega la dirección de este repositorio.
2. Abre la carpeta clonada.
3. Para ver la web, abre `index.html` en el navegador (doble clic) o usa la extensión **Live Server**.
4. Si usas Claude Code, el archivo `CLAUDE.md` le da todo el contexto del proyecto.

## Trabajar en equipo
- Antes de empezar: **Sincronizar** (o *Pull*) para traer los últimos cambios.
- Al terminar: en Control de código fuente, escribe un mensaje, pulsa **Commit** y luego **Sincronizar** (o *Push*).
- Intentad no editar la misma parte de `index.html` a la vez.
